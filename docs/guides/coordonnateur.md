# Guide du coordonnateur — console JE RELAIS

Vous ne voyez que les données de **vos communes**. Si vous êtes **suppléant**, vous recevez en plus les relais qui dépassent le délai de validation.

## Se connecter

Connectez-vous sur `/login` avec votre e-mail et votre mot de passe. Vous les avez définis grâce au lien d'activation reçu par e-mail.

La **double authentification** est obligatoire : à la première connexion, scannez le QR code avec une application d'authentification (Google Authenticator, Microsoft Authenticator…), puis conservez les codes de secours.

Appuyez sur ⌘K (ou Ctrl+K) pour rechercher une page.

## Recruter les Relais : Candidatures

1. **Candidatures** liste les dossiers de votre commune par date. Ouvrez un dossier pour voir l'identité, les pièces (consultations tracées), le selfie, la localité, la motivation et le score au quiz.
2. Comparez la photo du selfie avec la pièce d'identité. Une alerte apparaît en cas de doublon : même téléphone, même pièce ou même appareil.
3. Décidez :
   - **accepter** ;
   - **refuser** : motif choisi dans la liste et commentaire obligatoires ;
   - **mettre en attente** ;
   - **demander un complément**.

   Le candidat est prévenu.

## Valider les relais : Validation

1. La file est triée par urgence, puis par ancienneté. Un relais urgent déclenche un signal sonore.
2. Ouvrir un relais le **réserve 10 minutes** pour vous. Libérez-le si vous ne décidez pas.
3. Vérifiez avec le panneau de vérification :
   - la carte et l'écart entre le lieu déclaré et le GPS ;
   - la date de prise de vue et la date d'envoi ;
   - un média importé de la galerie ;
   - un doublon déjà envoyé ;
   - la fiabilité du Relais.

   Le lecteur permet de zoomer, d'avancer image par image et de changer la vitesse.
4. Décidez :
   - **valider** ;
   - **valider avec corrections** ;
   - **demander un complément** ;
   - **rejeter** avec un motif ;
   - **signaler comme sensible** à la rédaction.

   Pour un relais avec des mineurs ou des personnes identifiables, indiquez obligatoirement si un floutage est nécessaire.
5. La **note interne** est visible par la rédaction, jamais par le Relais.

**Délais cibles** : 30 min pour un relais urgent, 4 h pour un relais normal. Au-delà, le relais est signalé et remonte au suppléant, puis au superviseur régional, puis à l'administration.

## Gérer les Relais : Relais

La fiche d'un Relais présente son badge, son historique, ses statistiques et ses appareils connectés. Depuis cette fiche, vous pouvez :
- **suspendre** ou **radier** un Relais, avec un motif ; l'administration est informée ;
- **déconnecter un téléphone** perdu ou volé.

## Messagerie et appels

- **Messagerie** : répondez aux Relais, ou envoyez un message groupé à tous les Relais d'une commune.
- **Appels à relais** : relayez les appels de la rédaction, ou créez un appel local. L'accord de l'administration peut être requis.

## Tableau de bord
